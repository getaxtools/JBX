# Getting help

JBX is a personal open-source project, supported on a best-effort basis.

| You want to | Go to |
|---|---|
| Report a bug | [Open a bug report](https://github.com/getaxtools/JBX/issues/new?template=bug-report.yml) |
| Suggest a feature | [Open a feature request](https://github.com/getaxtools/JBX/issues/new?template=feature-request.yml) |
| Report a security problem | Follow [SECURITY.md](SECURITY.md). Never in a public issue. |
| Contribute a change | Read [CONTRIBUTING.md](CONTRIBUTING.md) |

Before you open an issue:

- Check you are on the [latest release](https://github.com/getaxtools/JBX/releases) and search the existing issues.
- Press <kbd>F1</kbd> in JBX for the version and every keyboard shortcut.
- If JBX shows a config problem, the message names the line and what to change.

**Never paste real paths, host names, share names, user names or log contents** into an issue. Replace them with made-up ones, for example `\\fs01.contoso.test\AppLogs`. A crash report from JBX already leaves them out, so it is safe to attach.
